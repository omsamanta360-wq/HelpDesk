# Help Desk - User Roles

## 1. Guest
Permissions:
- View Home Page
- Search Services
- View Public Profiles
- Read Reviews

Restrictions:
- Cannot Review
- Cannot Compare (Optional)
- Cannot Save Favorites

---

## 2. User
Permissions:
- Register/Login
- Search Services
- View Details
- Compare Services
- Write Reviews
- Give Ratings
- Save Favorites
- Manage Profile

---

## 3. Doctor
Permissions:
- Create Profile
- Edit Profile
- Manage Availability
- View Reviews
- Respond to Reviews (Future)

---

## 4. College Admin
Permissions:
- Manage College Profile
- Update Courses
- Update Fees
- Update Placements
- Upload Images

---

## 5. Hospital Admin
Permissions:
- Manage Hospital Profile
- Manage Departments
- Add Doctors
- Update Contact Information

---

## 6. Super Admin
Permissions:
- Manage Users
- Manage Doctors
- Manage Colleges
- Manage Hospitals
- Approve Listings
- Remove Fake Reviews
- View Analytics
- Manage Entire Platform
